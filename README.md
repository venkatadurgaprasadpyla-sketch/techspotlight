# TechSpotlight

Independent tech reviews and buying advice for India, built with Astro and Tailwind CSS.

## Getting started

Requires Node 22.12 or newer (`.nvmrc`).

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static output in dist/
npm run gates      # every automated quality gate
```

See [CLAUDE.md](CLAUDE.md) for architecture, the quality gates and the branch workflow. Deployment notes for Cloudflare Pages are added in a later task.
